# QPATutorialsCourse

Graded learnr tutorials for PLSC 309H: Quantitative Political Analysis 
at Penn State University. Tutorials use `gradethis` for exercise grading 
and `learnrhash` for Canvas submission.

## Installation

```r
devtools::install_github("slinnpsu/QPATutorialsCourse")
```

## Running a Tutorial

```r
learnr::run_tutorial("01-rBasics1", "QPATutorialsCourse")
```
